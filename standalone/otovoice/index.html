OtoVoice

発音の確認

文を書くと、その場で計算して声にします。1.4 で、声の出し方と子音を改良し、音素1つを1行に書いて細かく決める書き方（手で書く行）と、歌の音符ごとの指定を足しました。日本語と英語で、話すことも歌うこともできます。下のほうに、歌と楽器を合わせた曲も6つ置いてあります。読み方は、かなでも、音素でも書けます。下の欄で、書いた文がどう読まれるか（かな・音素・高さの動き）を見てから、鳴らしてください。録音は使っていません。

声の質 {f0, size, soft, bright, breathy, rough, shake, whisper}


    
上の「声」で見本かテンプレートを選ぶと、その値がここに写ります。切っているあいだは、選んだ声のままです。入れると、ここの数で鳴るので、選んだ声から少しずつ動かせます。歌声の高さは音符で決まるので、「高さ」は話し声だけに効きます。体の大きさは、1 が大人の男、1.15 が女、1.32 が子供です。文の中にも <size 1.2 soft 0.7> のように書けます。

      歌う OtoVoice.sing(譜面)
      
    
      
    譜面（音符の行と、歌詞の行を交互に）
    
    
      
    
        
    
        歌詞は、かな、/ / の日本語の音素、[ ] の英語の音節で書けます。1行にまぜても書けます。日本語は1拍、英語は1音節（空白で区切る）が、音符1つに当たります。英語の - は、前の音節を次の音符へ伸ばします。
        
    
        1.4 から、音符のうしろに指定を書けます。C4+30 はセント、C4:2{vib 1.5, rate 6, delay .3} はゆらしの深さ・速さ・遅れ、{scoop 1} は頭を下から入る半音、{p 0@0/-2@100} は音符の中の高さの線です。上の帯の「1.4 の改良」を入れていると、濁った子音で高さが少し沈み、大きく跳ぶ前に反対へ少し振れます（歌のこの2つは、まだ人が聴いて確かめていません）。
        
    
        声は、上の「声」で選んだものが歌にも効きます（「指定なし」のときは、譜面の voice onna の行のとおり）。歌の高さは音符で決まるので、声を変えても高さは変わりません。変わるのは、体の大きさ・やわらかさ・明るさ・息・ざらつき・ふるえ・囁きです。
        
  
        
  
        
    
        曲 TextScore.play(譜面)
        
    
        歌と楽器を合わせた、まるごとの曲です。押すと頭から鳴り、同じ曲をもう一度押すと止まります。「音声ファイルにする」で、曲を1つのファイルにして保存できます。
        
    
        
    
        
    
        曲を選んでください
        
    
        
    
        
    歌詞（主の声。歌っているところが朱になります）
    
        曲を鳴らすと、ここに歌詞が出ます。
        
    
        曲は、テキストの譜面を鳴らす基盤 TextScore（いまは 2.0.1）で書いてあります。2.0.0 から、OtoVoice と同じ1つのファイル（otostudio.js、このページと同じ場所にあります）になり、歌声の芯も1つになりました。歌声の、音符の頭の息の決め方を、2.0.2 で見直しました（裏声や囁きで、頭だけ雑音が強く出ていたのを直した）。そのぶん、どの曲も、歌声の音が少し変わっています。2.1.0 から、譜面の楽器名 voice は「女（平均）」、voicek は「子供」の声です（聴いて合わせた大きさ）。ここの曲は、これまでの音のまま鳴るように、as=onna・as=kodomo を書き足してあります。7つめの「零時の間取り」は、効果音を使わず、歌詞のない声（子供の鼻歌、女の裏声、男の低い声、囁き）を楽器として使った、4分のホラーの曲です（2分36秒に、大きな一撃があります）。8つめの「零時の間取り・しずけさ」は、その静かな場面だけを広げた曲で、声は女声だけ、エコーつきです。9つめの「零時の間取り・鼻歌」は、声をぜんぶ鼻歌（ん）にした版です。10 こめは、広告の頭と同じ子供の鼻歌だけで書いた版、11 こめは、その鼻歌の、息の設定の聴きくらべ（2.0.1 で足した bvow・inhale・batk）です。12 こめの「つめたい手」は、子供の鼻歌を使った、寒気のする新しい曲です。そのあとの3曲（かぞえうた「ひとつ ひろいし」、「あ の こもりうた」、「もう いい かい」）は、同じ作り（声と、オルゴールと、鐘）で書いた、ホラーの曲です。6つめの「ひかりのほうへ」は、2.0.0 で足した書き方（声のテンプレート as=yasashii、歌い方の改良 nat=1、音符の { }、音素の歌詞）の見本です。英語の歌詞は、譜面の歌詞の行に [ hoUld An tu D@ laIt ] のように音節で書いてあります。上の「声」「声の質」「無線機」「1.4 の改良」は、曲には効きません。曲の声は、譜面のトラックの設定で決めます。詞・旋律・伴奏とも、確認のために作ったものです。
        
    
        「音声ファイルにする」は、曲を頭から終わりまで書き出して（鳴らすときと同じ音。いちばん大きい所を −1dB にそろえます）、.mp4（AAC、192kbps）にします。ブラウザが AAC を作れないときは .webm（Opus、160kbps）です。音声だけの .mp4 は、.m4a と同じ中身です。3分の曲で、ファイルにするまで数十秒かかります。できあがると、保存してよいかの確認が出ます（claude.ai の中では .wav は渡せません）。「形式」で .wav（圧縮しない 16bit・48kHz。3分で約35MB）も選べます。できあがると、ブラウザのダウンロードに渡します。
        
    
        この表示では、曲をファイルにして渡す機能が使えません。

        書き方の早見
        
    
        
      
        書き方意味例
        
      
        
        かな自動の規則がかかる（です の「す」が落ちる、おう が おー になる、など）きょ'うわ い'い て'んきです。
        
        
        / … /日本語の音素。書いたとおりに読む/kjo':wa i': te'Nkides()./
        
        
        [ … ]英語の音素[ h@'loU 'w3ld ]
        
        
        'アクセントの核。その拍まで高く、次で下がる（英語では、強い音節の前）/a'me/ 雨　/ame/ 飴
        
        
        s()母音を落として、子音だけで切る/des()/ /mas()/
        
        
        k(u)母音の声を抜く（息だけで言う）/gak(u)se:/ /S(i)ta/
        
        
        : Q q長音、っ、ぷつっと切る/o:/ /kiQte/ /aq/
        
        
        m n N Xん（次の音に合わせて書き分ける）/sampo/ /kanda/ /kaNko:/ /hoX/
        
        
        歌詞の [ … ]英語の歌。音節ごとに空白で区切る（1音節が音符1つ）。- で次の音符へ伸ばす[ twIN k@l lI t@l stAr ]
        
        
        <rate 1.3>ここから速さを変える。ほかに pitch（半音）、vol、acc、decl、pause（秒）<pitch 3>ma'Qte<pitch 0>
        
        
        <size 1.2 soft 0.7>声の質を数で動かす。size（体の大きさ）soft（やわらかさ）bright（明るさ）breathy（息）rough（ざらつき）shake（ふるえ）whisper（囁き）{voice:'onna', size:1.25, rough:0.3}
        
        
        音符の { }歌の音符ごとの指定（1.4）。セントは C4+30E4:2{vib 1.4, delay .25}
        
        
        手で書く行音素1つを1行に（1.4）。項目は、上の「行を書く」の欄と、手引きにo 150 p +5.4 +1.8 soft .3
        
        
        <voice onna>息つぎのところで、声や調子を切りかえる。ほかに style、f0、scale、speed など<voice otoko style panic>

異論と提案

A. 適用領域の見せ方 意見

D は総和量なので、2D + e² < 1 が効くのは V が μ(1−μ) に O(1/n) まで迫るとき、つまりデータが「ほぼ二値」のときだけ（これは定義から直接）。タイトルと導入の「ありふれた集計値」は統計用途には過大に聞こえる。

主戦場を「ほぼ冪等な自己共役行列 0 ≤ X ≤ I」に置くほうが強いと思う。D = Tr(X − X²) は冪等誤差そのもの、s は階数（電子数）、η は trace のずれ。文献リスクが最も高いのもそこ。

提案：導入の第1段落で適用領域を明示する。行列版の T1（スペクトル分解経由）を主定理に格上げする案の是非は、Astra の判断を聞きたい。

B. η > 1/2 の成分分類 数値のみ

本文は「(8) は伸びない」で止めている。何が起きるかを n=2, s=1, η=0.9 で数えた。

δ=0.1 の4成分は、(1,0)・(0,1) の島に加えて、(1,1) 近傍の島と原点近傍の島。原点島では (0.1,0) と (0,0.1) が (0.05,0.05) 経由でつながり、上位ラベルが成分内で一定でない。δ=0.09 ではこの二つの島がそれぞれ二つに割れて6になる。

構造の読み：帯 [s−η, s+η] が隣の整数 s±1 の領域に食い込み、二値頂点を含まない「非整数型の島」（第6節の頂点 (r, 0, …) 型）が混ざる。「ラベルで成分を数える」枠組み自体が壊れる領域。

提案：残る課題に「η ∈ (1/2, 1) での #π₀(F_{s,η,δ}) の分類」を明記する。形式化の続きより、こちらのほうが数学として面白い。証明は未着手。

C. (16)(17) の帰属 検証済意見

balanced_error_sharp_bound は (16) ‖x−z‖₁ ≤ 1 − √(1−2D) を、Σu² ≤ (Σu)² を両側に当てるだけで直接証明している（ソースから確認）。第9節の Rastegin への還元は、証明としては不要で、純粋に書誌的な手続き。

Rastegin 自身が「max p 対 I の図は従来認識されていなかったようだ」と書いているので、引用そのものは妥当。ただ「Rastegin の既知不等式」という言い方は、将来の先行者探しで読者を 2023 年に誘導してしまう。

提案：「初等的（補題 (6) の一行の系。明示的記述は Rastegin 2023, Thm 1）」に言い換える。

D. T1 の陳述を Lean の形に揃える 意見

形式版は並べ替えを要求しない。任意の I（|I| = s）、a = argmin_I x、b = argmax_{Iᶜ} x について 2D + (S−s)² + (x_a − x_b)² ≥ 1。しかも rank_gap_core は u ≤ 1 と 0 ≤ v すら使っていない。

提案：本文 T1 をこの「ラベル自由形」で述べる。上位 s 集合を I に取れば従来の T1 になるので、第8節の「並べ替え列挙は未形式化」という注記は不要になる。本文の「順位ラベルの特定は主張しない」とも噛み合う。

Independent review of X01 v1.0 (2026-09-08) by Claude (claude-fable-5-1) on 2026-09-09.

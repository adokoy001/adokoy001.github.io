置き場所の確認

音を、頭のまわりの好きな場所に置いて聴くページです。図の上の点を指でつかんで動かすと、鳴ったまま、向きと遠さが変わります。ヘッドホンで聴いてください。計算は OtoFX.place をそのまま使っています。

置く OtoFX.place(x, {az, el, dist})

上から見た図（上が正面。点をつかんで動かす。輪は遠さ）
横から見た図（右が正面）。高さは、下のつまみで変えます。
効き具合（1 が、いまの既定）
左右の時間の差
空気での減り
書き方

動かして聴く {path:[[秒, az, el, dist], …]}

決まった道すじを、頭から終わりまで計算してから鳴らします。図の点が、音と一緒に動きます。上の「効き具合」は、ここにも効きます。

こだま OtoFX.echo(x, {size, amount, tail})

いまの場所に置いた音を1回だけ鳴らして、野外のこだま（0.36〜2.8 秒の返り5本と、長い尾）をかけます。

録音を聴く シャカシャカを、ひとつづきの道すじで動かしたもの（79 秒）

時刻動き
0〜9 秒正面 → 右へ跳ぶ → 左へ跳ぶ
10〜22 秒ゆっくり、ひと回り（正面 → 右 → うしろ → 左）
22〜30 秒逆向きに、速く ふた回り
31〜40 秒右ななめ前へ 12m まで遠ざかり、近づいてきて、右の耳もとへ
43〜49 秒頭のうしろを通って、左の耳もとへ
52〜62 秒正面で、上 → 下 → もとへ
62 秒〜まわりながら、上へ、遠くへ

40〜49 秒は耳もとで鳴るので、少し大きくなります。遠さでの音量の変わり方は、聴きやすいように4割に弱めてあります。

中身

手がかりしていることもと
左右の時間の差頭をまわりこむ道のりの差。真横で約 0.6 ミリ秒。耳は、真横より少しうしろ（±100°）にあるWoodworth の式、Brown と Duda
頭のかげ向こう側の耳は、高い音ほど小さいBrown と Duda（1998）
耳たぶの反射ごく短い遅れ5本。高さで間隔が変わり、高い帯域の谷が動く同じ（数は照合できていない）
前後・上下の色前は 500Hz と 4kHz が少し上がる。うしろはこもり、1kHz が少し上がる。上は 8kHz が上がる。下はこもるBlauert の帯域と、見積もり
空気での減り遠いほど、高い音が減る。300m 先の 8kHz で約 32dBISO 9613-1（20°C・湿度 50%）
部屋の響き遠いほど、もとの音に対する響きの割合が上がる見積もり

だれの耳も測っていないので、本物の HRTF ではありません。左右は、はっきり出ます。前後と上下は、聞こえ方が人によって大きくちがいます。もとの論文も、前半分だけを対象にしています。

小さな音で始めてください。音は、音の出ない環境で作ったもので、作り手（Claude）は耳で確かめていません。
